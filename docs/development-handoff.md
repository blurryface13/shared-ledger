以传统 Java 后端求职为主线，围绕共享账本、旅行规划、图片凭据与水印构建可解释的工程能力。保持 DDD 模块化单体；小程序优先设计，当前新界面仍是 Web 原型，不能宣称已完成小程序迁移。Agent 负责轻量意图识别与规划建议，核心校验、权限与事务由后端执行。水印算法等待用户提供，不虚构算法实现或性能结果。
