# 共享账本 UI 功能对照

更新：2026-09-20。`fronted/travel-prototype` 现在通过同源网关连接 Java API，不再将本地演示数据作为业务数据。原 uni-app 保留；本轮是响应式 Web 接入，尚未移植为小程序原生页面。

## 旧功能对应入口

| 功能 | 当前入口与接入范围 |
| --- | --- |
| 多账本 | Ledger 首页列出服务端账本、创建、切换；账本与行程可独立存在 |
| 账单 | 明细：个人收入/支出/结转、共享账单，分页、详情、编辑、删除、历史；凭据上传和鉴权读取 |
| 分摊 | 选择真实/临时成员、付款人；均摊、固定金额、比例；前端整数分计算，后端仍校验金额与权限 |
| 审批 | 修改/删除申请、我的申请、待审批、批准、拒绝、撤回 |
| 统计 | 总览、分类、成员承担与垫付、成员关系与临时成员追偿信息 |
| 成员 | 候选搜索、邀请、接受/拒绝/撤回、角色、移除、转让；临时成员创建、改名、挂靠、启停、删除 |
| 结算 | 批次、两种建议策略、手动付款/直接收款、收款确认/拒绝、历史、追偿；仅账务记录，不执行资金转账 |
| 设置 | 名称、描述、封面地址、个人预算、分类维护、退出/删除、导出历史、关联行程展示 |
| 导出 | 创建异步任务、查看状态、读取服务端快照、纸张预览、浏览器打印/保存 PDF；不是服务端生成 PDF 文件 |

前端组织为明细、统计、成员、审批、结算、设置，保留纸张预览和三个英文主入口。原后端权限、事务、账单版本与结算规则是权威边界。

## 尚未对齐的产品范围

- 账本没有新增归档接口；不再把本地“历史账本”伪装成服务器功能。行程支持归档/恢复。
- Gallery 尚未开放独立相册存储与分享；账单凭据从账单入口使用，水印算法等待后续接入。
- 登录页目前用于本地开发验证，生产微信登录、域名与小程序端接入仍需单独验收。
- 本轮覆盖接口和入口不等于每一种角色、审批、结算组合都已完成浏览器验收；服务端已有集成测试另见实施记录。
